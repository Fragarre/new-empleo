# Objetivo del proyecto

Construir desde cero un sistema para descubrir, interpretar, clasificar y actualizar oportunidades de empleo público de la Generalitat Valenciana (GVA) a partir de fuentes oficiales.
Las oportunidades válidas son las de oposiciones libres a puestos de administración, es decir a puestos clasificados como A1-01, A2-01, C1-01, C2-01; o puestos expresamente de caracter administrativo. 
No se considerarán ni promociones internas, ni libre designación, ni ninfuna otra que no sea oposición Libre
Debe obtenerse el número de plazas disponible para cada convocatoria de oposiciones
Deben obtenerse las fechas de inicio y fin de las convocatorias (en caso de que haya fecha fin) para presentar si la oportunidad esta en plazo de inscripción
Debe obtenerse la ficha completa de la convocatoria con todas las etapas
Debe incluirse en la base de datos existente en Supabase, TuCoach-Empleo, con todas las propiedades necesarias

No cambiar este alcance ni incorporar otros asuntos sin autorización expresa del usuario. Mantener la comunicación breve y centrada en el siguiente paso concreto.
